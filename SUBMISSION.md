# Touchline AI

Touchline AI is a broadcast desk for a fully synthetic 90-minute match. A NumPy telemetry engine reads the event stream, four specialised agents share one blackboard, and a grounding auditor refuses any number the tracking cannot prove. The picture on screen — a full-back stepping inside, a press that steals a goal, a card that kills the left side, a substitute who is simply faster — is computed, not scripted.

North London Red and Manchester Blue are fictional. There are no real clubs, crests, or league marks.

The same public URL serves the broadcast UI and the API. If the model is slow or the key is empty, the desk answers from deterministic templates and a precomputed cache, with the same badges the engine produced: PPDA 5.8, a 26.2 m inversion, CCI 79.4, a 33.8 km/h sprint, xG 1.84–1.42.

Built for the Microsoft "Inside the Game: Developer Hackathon" (Premier League Studio track) with Semantic Kernel orchestrating the agents, GitHub Actions proving the build, and VS Code as the authoring environment.
